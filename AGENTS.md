# AGENTS.md

Standard entry point for coding agents working in this repository.

Read `agent.md` for the canonical project context, course map, conventions, and editing guidance. `CLAUDE.md` contains Claude-specific guidance but should stay aligned with `agent.md`.

Important quick facts:

- This is a Jupyter notebook course repository for Maktab 141.
- Sessions currently run from `session01` through `session44`.
- Teaching content is primarily in `.ipynb` files.
- `samples/` contains small runnable examples used by notebooks.
- `images/` contains notebook assets.
- `requirement.txt` is pinned and should not be changed without explicit instruction.
- Preserve existing session numbering and notebook naming unless the user asks for a renumbering or rename.

Useful commands:

```bash
pip install -r requirement.txt
jupyter lab
jupyter notebook
```
